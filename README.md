# ZaiMiner

Minero para GPU NVIDIA (CUDA) en Windows x64.

## Descarga

**ZaiMiner 1.0 (Windows):** [descargas/ZaiMiner-1.0-windows.zip](https://github.com/zaidisk/Zaiminer/raw/main/descargas/ZaiMiner-1.0-windows.zip)

SHA256: `DE21F1682FED58F2159ACF8F4C88737B4E9A3BECDAC2464FB22B338656AA6ECB`

Uso: descomprimir, doble clic en `minar5.bat`, elegir algoritmo, poner pool y wallet, Iniciar. Ver `LEEME.txt`.

Algoritmos: QPoW, BLAKE3, QHash, Hoohash, RiecoinPoW, XelisHash v3, Argon2d, VerusHash 2.2, CryptoNight-GPU, GhostRider, Mike, MinotaurX, AQM64, Etchash, Ethash, KawPow, EvrProgPow, FiroPoW, ProgPowZ, ProgPow, FishHash, Autolykos2, Octopus.

## Comision

Comision declarada: 120 s cada 200 min (~1%) se mina para el autor, segun `comision.json`, la lista firmada de este repositorio.

`version.json` indica la ultima version; el panel avisa cuando hay una nueva.
